# Changelog

Every release of `@stackradar/node`, newest first. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/). While the version is `0.x`, a breaking change raises the minor version (`0.1.x` to `0.2.0`) and is listed first, under **Breaking changes**.
